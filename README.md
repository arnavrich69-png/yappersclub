## Golden rules (short version)

1. The thread crosses every post at the same height: **405 px** on 1080 x 1350, **672 px** on 1080 x 1920. Your grid becomes one string.
2. Red belongs to the thread only.
3. One seal per post. Venues are "PACKED AT".
4. No lyric text on cover clips. Lyric films are for members' own songs.
5. No instruments, mics, sound waves, neon or gradients. No dashes in copy.

Claude Code may improvise anything the brand rules don't fix.
